# 优化记录（2026-02）

本次优化针对仓库的**正确性、可维护性与静态资源缓存**，不改动页面渲染结果
（`Custom.xaml`、`panel.xaml` 保持逐字节不变）。

## 一、修复的缺陷

### 1. 死占位符 `__DATE_YEAR__`（静默故障）
`scripts/generate.py` 定义了 `year = "__DATE_YEAR__"`，`functions/_middleware.js`
也写了对应的替换语句，但 `Custom.xaml` 与 `panel.xaml` **都不含**该占位符。
即生成器与中间件长期维护着一个永远不会生效的替换。
（页面本身不显示年份，因此无可见影响，属于纯死代码。）

已从生成器与中间件两侧移除。

### 2. 主页分支存在 12 组无效占位符替换
中间件主页分支对 `Custom.xaml` 执行了若干模板中根本不存在的替换：

`__QUIZ_IMAGE__`、`__EGG_DATA__`、`__QUIZ_Q__`、`__QUIZ_A__`、`__QUIZ_TAG__`、
`__QUIZ_BG__`、`__QUIZ_ACCENT__`、`__QUIZ_NO__`、`__SCORE_COLOR__`、`__CHALLENGE_BG__`

这些只在 `panel.xaml` 中使用，属于中间件与模板职责划分混乱后的残留，
已连同它们对应的变量与计算一并删除。

> 附带发现：主页的天气数据目前只被上述死代码使用，而 `Custom.xaml` 的横幅
> 用的是生成期烘焙的 Bing 壁纸。天气本身仍用于主页的天气卡片，故保留调用。
> **若希望主页横幅也随实时天气变化，需要在模板中补回 `__QUIZ_IMAGE__` 占位符**，
> 这是产品决策，未擅自改动。

### 3. `_headers` 缓存规则指向不存在的目录（性能）
原规则为 `/images/hero/*.jpg`，但仓库中**没有 `images/hero/` 目录**
（横幅实际位于 `images/quiz/`）。结果是 34 张每日横幅图完全没有缓存头，
每次访问都会回源。已改为正确的 `/images/quiz/*.jpg`，并补充
`/images/icons/*.png`、`/images/version.png`、`/favicon.png` 的缓存规则。

### 4. CI 自我触发
机器人提交 `Custom.xaml` 等生成物后会再次触发 `push` 事件，
每次定时任务都白白多跑一轮。已通过 `paths-ignore` 排除生成物。

## 二、可维护性改进

### `functions/admin.js` 拆分（2065 行 → 1632 行）
按职责抽出三个模块（放在 `_lib/` 下，不会被当作路由）：

| 模块 | 内容 |
|---|---|
| `functions/_lib/admin-util.js` | 常量、Cookie、安全响应头、转义与格式化 |
| `functions/_lib/admin-theme.js` | 主题脚本、样式表、登录页 |
| `functions/_lib/admin-api.js` | Cloudflare GraphQL 与用量查询 |

拆分方式为**机械搬运**：逐行区间比对确认内容一字未改，仅新增 import/export。

### 新增校验脚本

| 脚本 | 作用 |
|---|---|
| `scripts/check_placeholders.py` | 校验模板 / 中间件 / 生成器三方占位符一致 |
| `scripts/check_imports.py` | 校验 `functions/` 下 ES 模块导入都能解析到真实导出 |
| `scripts/doctor.py` | 综合体检：文件完整性、JSON、JS 语法、图片引用、线上接口 |

前两个已接入 CI（生成前后各校验一次），可在故障进入线上之前拦截。

### 页面结构模板化（`generate.py` 1232 → 791 行）
原来 `build_xaml()` / `build_panel_xaml()` 用 **421 次 `lines.append(...)`** 在 Python 里
逐行拼接整页 XAML，合计 600 行、占 `generate.py` 的 49%；
而生成出的 `Custom.xaml` 有 **241/268 行是纯静态内容**，只有 27 行动态。
等于近 9 成页面结构被用 Python 字符串重写了一遍，改样式必须处理引号转义。

现在把静态结构移到 `templates/`，`generate.py` 只负责抓数据 + 填空：

| 文件 | 内容 |
|---|---|
| `templates/Custom.xaml.tpl` | 主页结构（含 26 个请求期占位符） |
| `templates/panel.xaml.tpl` | “更多功能”面板结构 |
| `templates/release_item.tpl` | “最近正式版”单条列表项 |
| `templates/server_item.tpl` | 服务器推荐单条 |

生成期 token 共 16 个（`{{MAIN_VERSION}}`、`{{WALLPAPER_URL}}`、`{{RELEASE_ITEMS}}` 等），
由 `render_template()` 替换；请求期占位符（`__USER_IP__` 等）原样保留给中间件。

同时修掉了模板化过程中暴露的两处原有缺陷：
- **版本封面三级兜底被写死**：`fetch_version_image` 失败本应回退到
  `fetch_official_version_image`，再兜底内置方块图，但模板里只用了 Wiki 图 URL。
  已提取 `resolve_version_image()` 恢复完整三级兜底。
- **域名硬编码**：版本图 URL 直接写死 `https://www.mkejga.de5.net`，
  现改为 `{{BASE_URL}}` 取自 `BASE_URL` 常量。

## 二、简介（直接复制）

```
一个自己写的 PCL2 联网自定义主页，每天打开都不一样。

【怎么用】
1. 打开 PCL2 → 设置 → 个性化 → 主页
2. 勾选「联网更新」，把下面这行粘贴进「下载地址」
   https://www.mkejga.de5.net/Custom.xaml
3. 回到主页，刷新一次即可看到效果

【对 PCL2 版本的要求】
需要 PCL2 2.10.4 或更高版本（用到了自定义卡片和图标按钮，旧版可能显示异常）

【主页有什么】
· 今日概览：每天的日期、每日一言、幸运数字、幸运颜色
· 你的信息：玩家 ID、公网 IP、实时天气（按你的 IP 定位）
· 今日运势：宜 / 忌 / 小贴士，还有人品评分与评级
· 今日种子、随机挑战：刷一下换一个
· 更多功能面板：每日一题（123 题）、神秘彩蛋、画板、常用指令速查、服务器推荐

【关于「每天都不一样」】
大部分内容是按「你的 IP + 当天日期」算出来的。
所以同一天里你自己看到的是固定的，但和别人的不一样；
第二天会自动换新。

【如果主页打不开或内容不更新】
关掉 PCL2 → 删除 %appdata%\PCL\Cache 这个文件夹 → 重新打开 PCL2

【彩蛋】
主页面板里有个彩蛋入口，点进去是个小网站，自己看吧。

用到的都是 PCL2 官方的自定义主页格式，不会修改游戏文件。
有问题欢迎评论区说，或者去 GitHub 提 issue。
```

## 八、需要你自己确认的两点

1. **字体差异**：主页用了 MiSans（你本机装的）。别人机器上若没装会**退回微软雅黑**，
   视频里展示的字体会比部分观众实际看到的更精致。心里有数即可，不必写进文案。

2. **天气依赖第三方接口**：天气数据来自外部 API，接口偶发失败时会显示
   「天气获取失败」，属正常情况，可在评论区说明。
